# 도움 벼룩시장

학생들이 "내가 줄 수 있는 도움"(초록)과 "받고 싶은 도움"(노랑)을 디지털 포스트잇으로 게시하고,
교실에서 직접 짝을 찾아 나눈 뒤 기록·성찰하는 학급 활동 웹앱.

> "받는 행복과 주는 행복, 오늘 둘 다 느껴보는 게 목표입니다."

## 구조 (이중 배포 모델)

- **Google Apps Script + 구글시트 DB** — 외부 서버·API 키 불필요, 서버 비용 0원
- 화면 3종: `index.html`(학생·모바일) / `board.html`(전광판·빔프로젝터) / `teacher.html`(교사)
- 각 화면은 **두 환경에서 동일하게 동작**:
  - **GAS 서빙** (시트 사본 배포용): 웹앱 URL `?view=board` / `?view=teacher` 로 분기, `google.script.run` 사용
  - **GitHub Pages** (원 개발자용): 정적 호스팅 + `?api=<GAS_배포_ID>` 로 doPost JSON API 호출 — git push 한 번으로 화면 업데이트

## 파일

| 파일 | 역할 |
|---|---|
| `Code.js` | doGet(화면 서빙) + doPost(JSON API) + 시트 커스텀 메뉴 |
| `Api.js` | 서버 로직 (입장/포스트잇/나눔 기록/성찰/교사 제어) |
| `Db.js` | 시트 스키마·헬퍼·설명서 탭 (학번 텍스트 서식 강제, lastModified 폴링 토큰) |
| `Seed.js` | 테스트 데이터 (가상 인물: 김하늘·이도윤·박새봄) |
| `index.html` `board.html` `teacher.html` | 화면 3종 (자체 완결형, 인라인 onclick 없음, SVG 아이콘) |

## 활동 흐름

대기 → 작성 → 시장 열림 → 성찰 → 종료 (교사 화면에서 단계 전환, 학생 화면 4초 폴링 자동 반영)

- 자유 시장(기본) / 짝 모드(무작위 2인, 홀수면 3인조)
- 한 포스트잇으로 여러 친구와 반복 나눔 가능 ("나눔 N회" 표시)
- 미매칭 포스트잇은 교사 화면에서 전광판 "주인을 찾습니다" 스포트라이트로 송출
- 부적절 포스트잇 숨김 처리
